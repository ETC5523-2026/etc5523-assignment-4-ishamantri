# bordercovid: Compare COVID-19 Outcomes Across Border-Closure Strategies

Provides a cleaned dataset of COVID-19 case and mortality rates for
countries that pursued strict border quarantine strategies alongside
comparison countries that did not. Includes a summary function and a
Shiny application for exploring how those outcomes differed across
countries and across time periods.
